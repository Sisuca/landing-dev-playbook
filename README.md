Una landing page interactiva que sirve como guía paso a paso para desarrollar proyectos web profesionales. Este proyecto demuestra habilidades en desarrollo frontend y gestión de proyectos.

## ✨ Características Principales

- ✅ **Checklist interactivo** con persistencia (localStorage)
- 📱 **Diseño completamente responsive** (mobile-first approach)
- 🎨 **Estilo moderno** con Tailwind CSS
- 🔄 **Actualización en tiempo real** con Live Server
- 📊 **Seguimiento visual de progreso**
- 🏗️ **Estructura profesional** de proyecto
- 📝 **Guía de mejores prácticas** para desarrollo web

## 🚀 Cómo Usar

### Clonar y Ejecutar Localmente

```bash
# 1. Clonar el repositorio
git clone https://github.com/Sisuca/landing-dev-playbook.git

# 2. Navegar al directorio del proyecto
cd landing-dev-playbook

# 3. Abrir en VS Code
code .

# 4. Ejecutar con Live Server
# Haz clic en "Go Live" en la esquina inferior derecha de VS Code
```

### Uso Directo en Navegador
Simplemente abre `index.html` en tu navegador favorito.
